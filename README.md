# Unsaid by Heart – Poetry Web App 💙

## 📌 Project Overview
Unsaid by Heart is a full-stack poetry sharing platform where users can explore, search, like, and comment on poems. The platform also includes an admin panel where poems are created and managed.
It is designed to create a simple and emotional space for expressing thoughts through poetry.

## 🌟 Features
### 👤 User Features
- User authentication (Google login)
- Browse and read poems
- Like poems ❤️
- Comment on poems 💬
- Search poems by title
- Sort poems (newest, oldest)
- Dark mode support 🌙
- Responsive design (mobile + desktop)

### 🛠️ Admin Features
- Admin dashboard for full control
- Create, update, and delete poems
- View all registered/logged-in users
- Track user engagement (likes & comments)
- See who liked and commented on poems
- Delete inappropriate comments
- Moderate and manage content
- Monitor platform activity
- 
## 🧠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT + Google OAuth

## 📂 Project Structure
- `public/` → Frontend (HTML, CSS, JS pages)
- `routes/` → API routes (users, poems, admin)
- `models/` → Database schemas
- `middleware/` → Authentication & security
- `server.js` → Main backend server
